# مبانی یادگیری ماشین

مخزن آموزشی دورهٔ «مبانی یادگیری ماشین» شامل نوت‌بوک‌های جلسات، راهنمای هر بخش و وابستگی‌های جداگانهٔ آن است.

## وضعیت انتشار

این مخزن در مرحلهٔ آماده‌سازی و **Private** است. پس از تکمیل داده‌ها، نسخهٔ نهایی Public می‌شود تا دانشجوها بتوانند آن را با **Download ZIP** یا **Clone** دریافت کنند. Follow کردن حساب مدرس برای آگاهی از دوره‌ها و به‌روزرسانی‌های آینده پیشنهاد می‌شود، اما جایگزین دسترسی به مخزن نیست.

## نقشهٔ دوره

## شروع سریع

1. این مخزن را Clone کنید یا با **Code → Download ZIP** دریافت کنید.
2. از ریشهٔ مخزن، وابستگیِ بخش موردنظر را نصب کنید. نمونه:

   ```bash
   pip install -r 01-linear-regression/requirements.txt
   ```

3. فایل‌های داده را در پوشهٔ ریشه‌ای [`data`](data/README.md) قرار دهید.
4. JupyterLab را از ریشهٔ مخزن اجرا کنید:

   ```bash
   jupyter lab
   ```

## یکپارچگی نوت‌بوک‌ها

نوت‌بوک‌های این مخزن عیناً از فایل‌های اصلی دوره کپی شده‌اند؛ کد، Markdown، خروجی‌ها و نام فایل‌ها دست‌کاری نشده‌اند. بعضی سلول‌ها مسیر مطلقِ رایانهٔ مدرس قبلی را دارند. این محدودیت در راهنمای بخش مربوط ثبت شده است تا در نسخهٔ اصلی تغییری ایجاد نشود.
