# 01 — رگرسیون خطی

این بخش مفاهیم رگرسیون خطی، تابع هزینه، MAE/MSE و گرادیان‌دسنت را پوشش می‌دهد.

## نوت‌بوک

`notebooks/chapter-2-linear-regression.ipynb`

## دادهٔ موردنیاز

- `data/student_loan_train.csv`
- `data/student_loan_test.csv`

## اجرا

از ریشهٔ مخزن اجرا کنید:

```bash
pip install -r 01-linear-regression/requirements.txt
jupyter lab
```

بخشی از سلول‌های نوت‌بوک، علاوه بر مسیر نسبی، به مسیر مطلق رایانهٔ قبلی اشاره دارند. نوت‌بوک طبق نسخهٔ اصلی، بدون تغییر نگهداری شده است.
