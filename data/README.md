# داده‌های دوره

فایل‌های دادهٔ هر بخش در این پوشه نگهداری می‌شوند.

## فایل‌های موردنیاز

| بخش | فایل‌ها |
| --- | --- |
| رگرسیون خطی | `student_loan_train.csv`، `student_loan_test.csv` |
| رگرسیون چندمتغیره | `usa-housing-train-preprocessed.csv`، `usa-housing-test-preprocessed.csv` |
| رگرسیون غیرخطی | `auto-train-preprocessed.csv`، `auto-test-preprocessed.csv`، `auto-train-multi.csv`، `auto-test-multi.csv` |
| انتخاب مدل | `energy-train-s.csv`، `energy-test-s.csv`، `energy-train-l.csv`، `energy-test-l.csv` |
| مینی‌پروژهٔ Housing | `housing.csv` |
| پروژهٔ Titanic | `titanic.csv` |

## نکتهٔ اجرایی

نوت‌بوک‌هایی که از مسیر نسبی `data/...` استفاده می‌کنند، با اجرای JupyterLab از ریشهٔ مخزن به این پوشه دسترسی خواهند داشت.
